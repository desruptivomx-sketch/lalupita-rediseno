# Propuesta de rediseño: Botanas La Lupita

Propuesta de sitio web para [Botanas La Lupita](https://la-lupita.com.mx) elaborada por **Desruptivo, Agencia Creativa Integral**, a partir de la revisión del sitio actual.

No es el sitio oficial. Las páginas llevan `noindex` para que Google no las muestre en lugar del sitio real.

## Qué corrige respecto al sitio actual

- Un solo H1 con el nombre de la marca, título y meta descripción propios, y etiquetas Open Graph para compartir.
- Sin el formulario interno de empleados.
- Teléfono, WhatsApp y correo como enlaces que se pueden tocar desde el celular.
- Sección de "Dónde comprar" y formulario de distribuidores que envía los datos por WhatsApp.
- Textos alternativos descriptivos, imágenes con carga diferida y botones en español.
- Enlaces a marcas del grupo con https y redes sociales iguales en todo el sitio.
- Enlace a aviso de privacidad (el texto está pendiente del área legal).

## Pendientes antes de publicarlo como sitio oficial

- Subir las imágenes al repositorio. Por ahora se cargan desde `la-lupita.com.mx`.
- Confirmar el correo de contacto (`contacto@lalupita.com`) y los enlaces de Midial3 y Doña Aida con https.
- Agregar el listado real de puntos de venta y el texto del aviso de privacidad.
- Quitar la barra de "propuesta" y la etiqueta `noindex`.

## Archivos

- `index.html`: página principal
- `styles.css`: estilos
- `script.js`: menú móvil y formulario de distribuidores
- `aviso-de-privacidad.html`: página reservada para el aviso
